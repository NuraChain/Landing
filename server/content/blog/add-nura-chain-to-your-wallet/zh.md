钱包并不预先知道每一条网络。在你能够在 Nura Chain 上持有余额、发送任何东西或打开某个应用之前，需要先告诉钱包这条网络的存在。整件事大约一分钟。

## 钱包会向你索取什么

六个值，每个钱包会索取其中的一部分：

- 网络名称：Nura Mainnet
- RPC URL：`https://rpc.nurachain.net`
- 链 ID：`1020`
- 货币符号：`NURA`
- 区块浏览器 URL：`https://explorer.nurachain.net`
- 小数位：18，多数钱包会自动填好

操作时把本页开着，或者更好的做法是独立核验链 ID——下一节会解释为什么这三十秒值得。

## 一键添加

多数浏览器钱包支持一个标准请求 EIP-3085，它允许页面一次性把整份网络定义交过去。Nura Chain 官网就用了它：首页和页脚的「Add Nura Chain to wallet」控件发送的正是上面这些值，你的钱包会把它们展示给你确认。

这是更值得优先选择的路径，原因与便利无关。手工输入链 ID 正是出错的那一步，而拼错的 RPC URL 更糟一层——它会把你的钱包指向由那个拼错域名的持有者所选定的服务器。

弹窗出现时请读它，而不是一路点过去。一个向你展示网络定义的钱包，展示的正是它即将信任的东西。

## 手动添加

如果你的钱包不支持自动请求，或者你根本不想让页面发起这种请求，每个钱包都有手动路径。在 MetaMask 中大致是：

1. 打开扩展顶部的网络选择器。
2. 选择「Add a custom network」（旧版本为：设置 → 网络 → 添加网络 → 手动添加）。
3. 填入上面的六个值。
4. 保存，然后切换到新网络。

其他钱包措辞不同，但索取的字段相同，因为这些字段来自标准而非钱包。

## 确认你确实在 Nura Chain 上

别跳过这一步。钱包会毫无怨言地保存一条「名字说的是一回事、RPC 指向另一处」的网络，因为名字是你自己敲进去的标签，而 RPC 才是它真正对话的对象。

端点会自报身份：

```bash
curl -s https://rpc.nurachain.net -X POST \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'
```

回答是 `{"jsonrpc":"2.0","id":1,"result":"0x3fc"}`。`0x3fc` 的十进制是 1020，它必须与钱包显示的链 ID 一致。若两者不符，请先停下并修正网络条目，再发送任何东西。

如果你不想用终端，就打开 [Nura Explorer](https://explorer.nurachain.net)，把最近的区块号与钱包报告的数字对照。浏览器和钱包读到同一条链，就是同一项核验换了条路径。

## Nura Wallet

也有一款专为这条网络打造的钱包。Nura Wallet 是自托管的——私钥留在你的设备上——并提供 Android、Windows 和 Linux 版本，首页有下载链接。它出厂即配置好网络，因此整套流程都可以省掉。

它不是必需品。Nura Chain 是一条普通的 EVM 网络，任何支持自定义网络的钱包都可以用，这正是[EVM 兼容](/blog/nura-chain-evm-compatibility)的意义所在。用你本来就信任的那一个。

## 出问题时

- **钱包拒绝链 ID。** 几乎总是十进制与十六进制形式弄混了。`1020` 和 `0x3fc` 是同一个数，而输入 `0x1020` 不是。
- **余额显示为零。** 检查当前选中的是哪条网络。同一个地址在每条 EVM 链上都存在，所以指向错误网络的钱包会给你看一个真实地址和一份毫不相干的余额。
- **交易一直不确认。** 通常是从另一条网络沿用下来的 gas 价格。让钱包自己估算，别去覆盖它。
- **符号显示成别的。** 属于外观问题，编辑网络条目即可修正，不影响网络的实际行为。

## 常见问题

### 添加网络本身有风险吗？

添加网络不会转移资金，也不会授予任何应用权限。真正重要的是你指向哪个 RPC URL，因为那是你的钱包查询余额、发送交易所经由的服务器。用一个你有理由信任的，并核验它的链 ID。

### 添加网络前需要先有 NURA 吗？

不需要。添加本身不花钱。但在发送交易之前你会需要 NURA 余额，因为 gas 用原生代币支付。

### 我能用已经有的那个地址吗？

可以。你的地址由私钥派生，因此在每条 EVM 网络上都相同。不过余额和历史是按链分开的——[什么是 Nura Chain](/blog/what-is-nura-chain) 解释了这一区分为何重要。

### 以后怎么移除这条网络？

从当初添加它的那个设置页面。移除网络不会影响任何余额，只是让那个钱包不再显示这条链。
